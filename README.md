# 🌍 Global GDP Intelligence Dashboard

Questa è una dashboard interattiva professionale sviluppata con **Streamlit** per l'analisi e la visualizzazione del PIL (Prodotto Interno Lordo) mondiale. Il progetto mira a fornire insight rapidi e chiari sui dati macroeconomici globali.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://gdp-dashboard-cvfuyi2oeidryuefclfiqh.streamlit.app/)

## 🚀 Demo Live
Puoi accedere all'applicazione completa qui: [Global GDP Intelligence Dashboard](https://gdp-dashboard-cvfuyi2oeidryuefclfiqh.streamlit.app/)

## ✨ Caratteristiche
- **Analisi Multi-Paese**: Confronto diretto tra le economie mondiali.
- **Interfaccia Ottimizzata**: Layout responsive progettato per la massima leggibilità.
- **Grafici Dinamici**: Visualizzazioni interattive per esplorare i trend storici.

## 🛠️ Tecnologie Utilizzate
- **Python**: Core logic dell'applicazione.
- **Streamlit**: Framework per la creazione della web app.
- **Pandas**: Elaborazione e analisi dei dati economici.
- **Plotly/Altair**: Per la generazione di grafici interattivi.

## ⚙️ Installazione Locale
Se vuoi eseguire il progetto sul tuo computer:
1. Installa le dipendenze: `pip install -r requirements.txt`
2. Avvia l'app: `streamlit run streamlit_app.py`
